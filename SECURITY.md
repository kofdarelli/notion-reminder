# Security Policy

Security fixes target the latest code on `main`.

Do not report vulnerabilities in a public issue. Use GitHub private vulnerability reporting when available, or contact the maintainer through [kofdarelli.com/contact](https://kofdarelli.com/contact).

Include the affected component, reproduction conditions, likely impact, and a safe proof of concept. Do not access data that is not yours, send email to third parties, or expose Notion and Gmail credentials while testing.
